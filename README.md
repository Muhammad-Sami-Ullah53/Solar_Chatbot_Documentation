## 📌 Project Overview

**Solar AI Pakistan** is a Pakistan-focused solar energy project designed around a **Retrieval-Augmented Generation (RAG)** approach.

The purpose of this project is to provide users with useful and understandable information about solar energy, solar products, pricing, installation, batteries, inverters, solar panels, net metering/net billing, and other Pakistan-specific solar topics.

My contribution to the project was the preparation of the **solar knowledge base** that will later be used by the RAG pipeline for document retrieval, embeddings, and vector search.

Instead of keeping the research as random notes or unstructured website content, I researched, cleaned, organized, and converted the information into structured Markdown documents.

The main goal of my work was to create reliable and organized knowledge that can later be used by a RAG system.
